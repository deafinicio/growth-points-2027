# Точки зростання · 2027 — «Дерево спроможності»

Кінематографічна інтерактивна заготовка презентації на 90 днів для Харківської, Чернігівської та Сумської областей. Запитання з наданого PDF збережені; фактичні відповіді початково порожні.

## Сценарій: 9 відповідей → 3 частини → 1 дерево

- На початку — зерно світла над водою та слабкий силует майбутнього дерева. На головному екрані лише назва, області та «Почати».
- **Січень:** три відповіді вирощують три корені. Завершення місяця об’єднує кореневу систему та вирощує переплетений стовбур.
- **Лютий:** п’ять відповідей додають п’ять головних гілок із розгалуженнями та напівпрозорим листям. Разом вони формують крону.
- **Березень:** відповідь про дані й спроможність створює світловий скляний плід. У фіналі камера показує ціле дерево.

Відповідь презентовано, коли доповідач натискає **«Додати до дерева»** або Page Down. Саме відкриття вкладки чи заповнення тексту не позначає її презентованою. Обговорення трьох регіональних вкладок завершується одним внеском у дерево на запитання.

Камера, матеріали, водна поверхня, світлові потоки й частинки залишаються у сцені протягом виступу. Під час росту панель відповіді зникає. Між місяцями — окремі сцени зібраного результату. Перехід до наступного місяця виконує доповідач.

Повернення до запитання зберігає побудовані частини; повторне проходження не дублює елемент. «Почати» / «Від початку» запускають нову побудову та зберігають текст відповідей. Побудова — стан поточного показу, який скидається після перезавантаження сторінки.

## Зображення та анімація

React 19, Three.js r187, React Three Fiber 9, Drei 10, Motion 14, React Postprocessing 3, Vite 8. Точні версії зафіксовані у `package-lock.json`.

- Процедурна просторова модель: три корені, три переплетені стовбури, п’ять головних гілок, 50 другорядних гілок, 500 скляних листків.
- Поступове відкриття геометрії, плавне зростання листя, легке коливання крони.
- Фізичні матеріали: transmission, товщина, IOR, clearcoat та iridescence.
- Світлові прожилки з GLSL-потоками та рухомими краплями, деформований прозорий плід із яскравим ядром.
- Динамічне дзеркало водної поверхні, shader-хвилі, м’яке bloom-світіння, студійні відбиття світла, туман, частинки та рух камери.
- **Рідина:** обчислювана 2D-сітка швидкості, pressure projection, semi-Lagrangian advection та RGB-барвник. Поле керує забарвленням води та викривленням віддзеркалення. Це не тривимірна SPH/FLIP-симуляція всієї геометрії дерева; скляні гілки та форма плоду мають окремі анімації.
- Кінематографічний / економний режими; автоматичне зменшення деталізації при низькій продуктивності, DPR обмежено.
- Світла й темна теми. `prefers-reduced-motion` скорочує переходи та вимикає постійний рух; ручна пауза доступна в налаштуваннях.
- Без WebGL працює анімований Canvas2D renderer: він проектує ту саму 3D-модель і використовує ту саму симуляцію барвника. GPU-заломлення та дзеркальне відображення доступні в основному WebGL2-режимі.

Зовнішні CDN, платні API, ключі та завантаження HDRI не потрібні. Шрифт Manrope включено до збірки; освітлення створюється процедурно.

## Відповіді та сумісність

Схему даних першої версії та ключ локального збереження збережено: існуючі JSON-файли й локальні відповіді сумісні.

1. Відкрийте запитання та обласну вкладку.
2. Натисніть «Заповнити», введіть текст, потім «Готово».
3. Текст автоматично зберігається **лише в цьому браузері**. Публікація в GitHub не відбувається.
4. Налаштування → «Експортувати відповіді» завантажує JSON усього набору. На іншому комп’ютері використайте «Імпортувати відповіді».
5. Імпорт перевіряє структуру та всі поля, показує підтвердження перед заміною поточних даних і пропонує експорт поточної версії.
6. «Спільне рішення» в кожному запитанні — узгоджена відповідь кластеру. Зведення доступне через «Запитання й спільні рішення» та у фіналі.

Експорт містить всі області й спільні рішення. Автоматичного злиття окремо підготовлених регіональних файлів та одночасного онлайн-редагування немає. Передавайте один спільний JSON послідовно або об’єднайте потрібні вкладки в `answers` вручну.

Для публікації відповідей для всіх замініть `public/data/presentation.json` експортованим JSON та зробіть commit. Збережені локальні відповіді мають пріоритет; для оновлення такого браузера імпортуйте новий JSON. Репозиторій і Pages публічні — додавайте в опублікований файл тільки інформацію, призначену для відкритої презентації.

## Керування

| Клавіша | Дія |
| --- | --- |
| → / Page Down / Пробіл | Почати / додати елемент / наступний місяць |
| ← / Page Up | Назад до запитання |
| 1 / 2 / 3 / 4 | Обласні вкладки / спільне рішення |
| F | Повний екран |
| T | Світла / темна тема |
| ? | Довідка |
| Esc | Закрити діалог / редагування, інакше на початок |
| Home | На початок |

Під час анімації повторний клік «Далі» ігнорується. Для прискорення показу є «Пропустити анімацію». Пауза також призупиняє автоматичне завершення сцени росту. У полі відповіді клавіші працюють як під час звичайного редагування; стрілки у вкладках перемикають області.

## Перевірки

Тести перевіряють всі дев’ять запитань, експорт/імпорт, відхилення некоректних даних, каскад 3/5/1, переходи назад, повторні натискання, захист від передчасних переходів, зменшення дивергенції поля швидкості та стабільність симуляції барвника. Production build проходить.

У віддаленому браузері перевіряються компонування, регіональні вкладки, редагування, послідовність показу й Canvas2D-сцена. WebGL у цьому браузері вимкнено, тому вигляд GPU-матеріалів, сумісність усіх shader-ефектів під час виконання та FPS на відеокарті тут повністю не перевірені.
