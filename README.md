# Точки зростання · 2027

Інтерактивна 3D-заготовка презентації наступних 90 днів для **Харківської, Чернігівської та Сумської областей**. Запитання відтворено з наданого документа «Точка зростання: наступні 90 днів»; усі відповіді початково порожні.

## Презентація

- Три композиції: розділена піраміда, орбіти, траєкторія. Перемикання плавно перебудовує геометрію.
- Рівні: січень — запуск; лютий — якість і масштабування; березень — підсумки та спроможність.
- Кнопки 01 / 02 / 03 показують рівні від основи. «Побудувати» послідовно додає всі три рівні.
- Натиснення на рівень або картку відкриває етап: 3 + 5 + 1 запитання.
- У кожному запитанні — три обласні вкладки та «Спільне рішення». Фінальний екран збирає спільні рішення всіх етапів.
- Світла й темна теми, повний екран, керування клікером, reduced motion.
- Якщо WebGL недоступний, працює векторна просторова сцена з тими самими композиціями й переходами.

## Як заповнювати

1. Відкрийте етап, запитання та вкладку області.
2. Натисніть **«Заповнити»**, введіть текст і натисніть **«Готово»**.
3. Зміни автоматично зберігаються **лише у цьому браузері**. Вони не надсилаються на сервер і не редагують GitHub.
4. Налаштування → **«Експортувати відповіді»** завантажує весь набір у JSON. Для іншого комп’ютера використайте **«Імпортувати відповіді»**. Перед заміною поточних відповідей показується підтвердження.
5. Щоб опублікувати узгоджені відповіді для всіх, замініть `public/data/presentation.json` експортованим JSON та зробіть commit. Існуючі локальні відповіді мають пріоритет; для оновлення такого браузера імпортуйте новий JSON.

Експорт завжди містить **усі** відповіді, а не лише поточну область. Для підготовки областями окремих файлів об’єднайте їх вкладки в `answers` вручну або передавайте один спільний JSON послідовно. Автоматичного злиття та одночасного спільного редагування немає.

**Увага:** цей репозиторій і GitHub Pages публічні. Додавайте до опублікованого JSON тільки дані, призначені для відкритої презентації. Локальне редагування саме по собі нічого не публікує.

## Керування

| Клавіша | Дія |
| --- | --- |
| → / Page Down / Пробіл | Наступне запитання |
| ← / Page Up | Попереднє запитання |
| Esc / Home | Загальна сцена |
| 1 / 2 / 3 / 4 | Харківська / Чернігівська / Сумська / спільне рішення |
| F | Повний екран |
| T | Тема |
| ? | Довідка |

У полі відповіді клавіші працюють як під час звичайного редагування тексту. Стрілки у вкладках перемикають області.

## Розробка

```bash
npm ci
npm run dev
npm test
npm run build
```

Node.js 24. React 19, Three.js r187, React Three Fiber 9, Drei 10, Motion 14, Vite 8. Точні версії залежностей зафіксовані у `package-lock.json`. Використано стабільний WebGL2 renderer, фізичні матеріали, процедурне студійне освітлення та GLSL-хвилі. Хвильова поверхня — візуальний ефект, а не фізична симуляція рідини. Шрифти Manrope включено до збірки; зовнішні CDN, платні API, облікові записи та ключі не потрібні.

- `src/content.js` — текст запитань, етапів, вкладок та описів.
- `src/Scene.jsx` — 3D та резервна просторова сцена.
- `src/main.jsx` — навігація, редагування, теми, імпорт/експорт.
- `src/data.js` — схема, перевірка та підрахунок заповнення.
- `src/style.css` — дизайн і адаптація під розмір екрана.
- `public/data/presentation.json` — опубліковані відповіді.

GitHub Pages налаштовано через `.github/workflows/deploy.yml`: перевірки → production build → публікація `dist`. У Settings → Pages джерело — **GitHub Actions**. Відносний `base: './'` підтримує розміщення в підкаталозі репозиторію.

## Перевірки першої версії

`npm test` перевіряє структуру всіх 9 запитань, повний цикл експорту/імпорту українського тексту, відхилення некоректних файлів і підрахунок заповнення. Production build проходить. У браузері перевірено переходи, вкладки, редагування, відновлення після перезавантаження, теми, фінальний екран і резервну сцену. У віддаленому браузері WebGL вимкнено, тому GPU-відтворення та фактичний FPS там не перевірялися.
